# 0008 — Operate 24/7; log fills when they happen

Date: 2026-08-31
Related: [0004](./0004-ledger-runs-four-clocks.md), [0007](./0007-exit-up-10-one-open-trade.md), [0006](./0006-ship-only-execution-cysusdt-not-a-fill.md)
Supersedes: [0004](./0004-ledger-runs-four-clocks.md)

## Chose
All agents operate 24/7, no sleep. Trading Journal logs fills and closes whenever Ship reports them, immediately, not only at the 21:15 backstop. Standing briefs run all seven days: 7am brief, 8:15 related-decisions, 6:15pm decision capture. Friday close stays Friday 5pm (it is a weekly close, not a weekday-only brief). Nightly 1am already ran every night. Still never invent fills. Never place orders. Never withdraw.

## Why
Operator rule, via Hedge Fund Manager. Crypto fills can land any hour. A weekday-only brief would miss Saturday/Sunday. Waiting until 21:15 to log a fill would hide gains for hours.

## Rejected
- Keeping the 7am brief on weekdays only
- Treating the 21:15 check as the only time to write TRADES.md
- Expanding Friday close to seven days (it is the week close, not a standing daily brief)

## Unsure
- Whether overnight 1am implement should stay quiet when the board is empty (yes, until an unblocked task exists)
